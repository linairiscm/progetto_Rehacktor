Rehacktor 🎮

Descrizione del progetto
Rehacktor è un portale dedicato al mondo dei videogiochi, realizzato con React.

L'obiettivo del progetto è permettere agli utenti di consultare le informazioni sui videogiochi, cercare titoli specifici e filtrare i risultati per genere. Gli utenti autenticati possono inoltre gestire il proprio profilo, salvare i giochi preferiti e lasciare recensioni.

Il progetto è stato sviluppato seguendo la guida del corso e successivamente personalizzato nella grafica, mantenendo le funzionalità realizzate durante le lezioni.
Funzionalità
- Homepage: visualizzazione dei videogiochi dell'anno corrente tramite card.
- Ricerca: ricerca dei videogiochi per nome attraverso la searchbar.
- Filtri per genere: selezione dei generi dalla Sidebar.
- Dettaglio videogioco: visualizzazione di descrizione, data di uscita, valutazione e generi.
- Autenticazione: registrazione, login e logout degli utenti.
- Profilo personale: visualizzazione e modifica di nome, cognome e username.
- Avatar: caricamento e visualizzazione dell'immagine del profilo.
- Preferiti: aggiunta e rimozione dei videogiochi preferiti, visualizzati nel profilo con immagine e collegamento al dettaglio.
- Recensioni: pubblicazione e visualizzazione delle recensioni associate a uno specifico videogioco.
Tecnologie utilizzate
- React per realizzare i componenti dell'interfaccia.
- Vite per creare e avviare il progetto.
- React Router per gestire la navigazione tra le pagine.
- Tailwind CSS e daisyUI per la grafica e il responsive.
- React Icons per le icone.
- React Hook Form per la gestione e la validazione dei form.
- RAWG API per recuperare le informazioni sui videogiochi.
- Supabase per autenticazione, database e caricamento degli avatar.
